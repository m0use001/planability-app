# i18n guide

**Current state:** the app UI is Chinese (zh-CN) only. User-facing strings are
written inline in Compose code (`Text("…")`) and in the desktop renderer
(TS/JSX); they are not yet externalized. This is a known limitation, tracked
for future work — contributions are welcome.

## Where strings live

| Layer | Location | State |
|---|---|---|
| Android Manifest / launcher / widgets | `app/src/main/res/values/strings.xml` | externalized (19 entries); English seed at `values-en/strings.xml` |
| Android UI (Compose) | inline `Text("…")` in `app/src/main/java/.../ui/**` | **not externalized** (~1,000+ strings across ~50 files) |
| Desktop renderer | inline Chinese literals in `desktop/src/renderer/src/pages/**` | **not externalized** |
| AI prompt templates / role-card data | `ai/**` prompt builders | Chinese by design (model-facing), see below |

## How to contribute a translation

1. **Manifest-level strings** — translate directly in a new
   `values-<locale>/strings.xml` (see `values-en/strings.xml` for the seed).
   These take effect immediately (launcher shortcuts, widget picker).
2. **In-app UI strings** — these first need extraction: move literals into
   `values/strings.xml` (Chinese source of truth) and reference them via
   `stringResource(R.string.xxx)`. If you take on a screen, please extract the
   whole screen in one PR (mixed extracted/inline strings in one screen are
   harder to review than a clean switch). Suggested naming:
   `screen_purpose`, e.g. `notes_editor_delete_confirm`.
3. **Desktop** — mirror the same string keys in a `shared/strings.<locale>.ts`
   module once the first screen lands; keep the key names identical to the
   Android side (the two ends share no code, contracts are manual — see
   `desktop/shared/`).
4. **AI prompt templates stay Chinese for now.** They are model-facing
   instructions tuned for the bundled Chinese role-card data; translating them
   changes model behaviour, not just labels. Treat them as out of scope until
   there is a dedicated design.

## Conventions

- Keep `values/strings.xml` (default) as zh-CN source of truth; every locale
  directory overrides, never duplicates comments.
- Widget/shortcut names should stay short (launcher space is tight).
- Don't translate user-visible product nouns inconsistently — check existing
  translations first (`中枢` = hub, `待办` = to-do, `倒数日` = countdown).
